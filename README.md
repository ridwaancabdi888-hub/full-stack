# Full-stack practice

A collection of beginner HTML exercises covering tables, forms, links, images, video, lists, and navigation between pages.

## Files

- `first.html` — links, media, and list examples
- `sec.html` — second page used for navigation practice
- `table.html` — table and form controls
- `assegment.html` — student registration form and table exercise
- `B.mp4` — local video used by the media example

## Run locally

No dependencies or build step are required. From the repository folder, start a local server:

```bash
# macOS or Linux
python3 -m http.server 8000

# Windows
py -m http.server 8000
```

Open `http://localhost:8000/first.html` in a browser. Stop the server with `Ctrl+C`.
